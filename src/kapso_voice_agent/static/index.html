Sign in to this server

Enter the console access key of this server. It is not your Kapso, ElevenLabs or xAI key.

This browser tab keeps the key until you close the tab.

Where do I find the key?
  1. Open a terminal in the project folder, on the computer that runs the server.
  2. Run uv run voice-agent console-key. It copies the key to your clipboard and does not show it.
  3. Paste the key above and select Sign in.

The key is OPERATOR_TOKEN in the .env file of the server. On Railway, it is the OPERATOR_TOKEN variable of the service. If you change it, restart the server.

Setup

To change a setting, run uv run voice-agent setup, then restart the server.
