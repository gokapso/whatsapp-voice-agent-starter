Sign in to this server

Enter this server's console access key. It lets you start test calls and outbound calls. It is not your Kapso, ElevenLabs or xAI API key.

The key stays in this browser tab and is forgotten when you close the tab.

Where do I find the key?
  1. On the computer that runs the server, open a terminal in the project folder.
  2. Run uv run voice-agent console-key. It copies the key to your clipboard without showing it.
  3. Paste it above and select Sign in.

The key is OPERATOR_TOKEN in the server's .env file, which voice-agent setup created. On Railway, it is the service's OPERATOR_TOKEN variable. If you change it, restart the server and sign in again.
